# Симулятор Разработчика (Roblox)

Симулятор-кликер: игрок пишет код, продаёт его, качает апгрейды, делает
ребёрты и открывает зоны от гаража до космоса.

## Структура

| Путь | Что это |
|---|---|
| `roblox-devsim/src/shared/Config.lua` | все настройки: ID геймпассов/товаров, зоны, награды, коды, цены |
| `roblox-devsim/src/shared/MapKit.lua` | примитивы карты (дома, деревья, пады, мосты, ворота, анимации по тегам) |
| `roblox-devsim/src/shared/MapBuilder.lua` | сборка карты: 5 островов + мосты + хаб + VIP-лофт |
| `roblox-devsim/src/server/MainServer.server.lua` | логика, монетизация, награды, лидерборды, админка |
| `roblox-devsim/src/client/ClientMain.client.lua` | интерфейс, свет под зону, колесо удачи |
| `roblox-devsim/tools/build_place.py` | сборка `.rbxlx` (только Python 3) |
| `roblox-devsim/build/DevSim.rbxlx` | собранный результат, коммитится в репозиторий |

Модули едут в `ReplicatedStorage.DevSim`, сервер — в `ServerScriptService`,
клиент — в `StarterPlayer.StarterPlayerScripts`. Карта строится кодом при
запуске, в файле места её нет.

## Правила кода

* **Только синтаксис Lua 5.1.** Никаких `+=`, `continue`, `//` и типов
  Luau — иначе перестанет работать проверка `check_lua.js`. Пиши
  `x = x + 1`.
* Комментарии и тексты интерфейса — по-русски, как в остальном коде.
* Новые настройки — в `Config.lua`, а не в середине логики.
* Анимация декора вешается тегами (`Kit.markSpin` / `markBob` /
  `markPulse` / `markOrbit`) и крутится на клиенте. Не двигай декор
  с сервера — это сетевой трафик на каждый кадр.
* Любое действие игрока с сервера проходит через `throttle(...)`.
* ID товаров с нулём — нормальная ситуация: кнопка показывает «СКОРО».

## После любой правки

```bash
npm install --no-save luaparse                       # один раз
node roblox-devsim/tools/check_lua.js roblox-devsim/src
python3 roblox-devsim/tools/build_place.py           # пересобрать .rbxlx
```

Пересобранный `build/DevSim.rbxlx` нужно коммитить вместе с исходниками —
пользователь скачивает именно его.

## Чего не делать

* Не переименовывать существующие ремоуты и поля в сохранении
  (`STORE_KEY = "DevSim_v2"`) — сломается прогресс живых игроков.
* Не вписывать в код ключи Open Cloud и любые токены: они живут только
  в секретах GitHub.
