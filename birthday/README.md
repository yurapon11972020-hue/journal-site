# Поздравление с днём рождения · 17 сентября

Статичный сайт-открытка. Никакой сборки: открывается двойным кликом
по `index.html` или отдаётся любым статик-хостингом.

```
birthday/
├── index.html   структура страниц
├── styles.css   оформление (чёрный · белый · розовый)
├── script.js    отсчёт, поляроиды, лайтбокс, лепестки
├── config.js    ← ЕДИНСТВЕННЫЙ файл для правок
└── photos/      сюда кладём фотографии
```

## Что править

Всё в `config.js`:

| Поле | Что это |
|---|---|
| `name` | имя именинницы на первом экране |
| `from` | от кого (подпись в финале) |
| `day`, `month` | дата рождения — год подставляется сам |
| `heroPhotos` | 3 «разбросанных» снимка на первом экране |
| `photos` | галерея поляроидов |
| `wishes` | список пожеланий |

## Как добавить фото

1. Положить файл в `photos/`, например `photos/1.jpg`.
2. В `config.js` заменить `src: null` на `src: 'photos/1.jpg'`.

Кадры лучше квадратные — рамка кадрирует по центру.

## Локальный просмотр

```bash
cd birthday
python3 -m http.server 8080
# открыть http://localhost:8080
```

## Что внутри

- первый экран с именем, датой и парящими поляроидами;
- живой обратный отсчёт до 17 сентября (в сам день — отдельная надпись);
- письмо на «бумаге» со скотчем;
- галерея поляроидов с открытием по клику;
- пять коротких пожеланий;
- финал с подписью.

Уважает `prefers-reduced-motion`: при включённой настройке анимации выключаются.
