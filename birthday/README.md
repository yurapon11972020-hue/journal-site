# Поздравление с днём рождения · 17 сентября

Статичный сайт-открытка в чёрно-бело-розовой альт-эстетике: сканлайны,
зерно, глитч, бегущие строки и шашечки. Никакой сборки — открывается
двойным кликом по `index.html` или отдаётся любым статик-хостингом.

```
birthday/
├── index.html   структура страниц
├── styles.css   оформление
├── script.js    отсчёт, поляроиды, просмотр фото, звёздочки
├── config.js    ← ЕДИНСТВЕННЫЙ файл для правок
├── fonts.css    подключение шрифтов
├── fonts/       шрифты, сохранённые локально
└── photos/      сюда кладём фотографии
```

## Что править

Всё в `config.js`:

| Поле | Что это |
|---|---|
| `name` | имя именинницы — первый экран и бегущая строка |
| `signature` | подпись — первый экран, бегущая строка, финал |
| `day`, `month` | дата рождения — год подставляется сам |
| `photos` | 9 поляроидов, разбросанных по странице |
| `wishes` | список пожеланий |

## Как добавить фото

1. Положить файл в `photos/`, например `photos/1.jpg`.
2. В `config.js` заменить `src: null` на `src: 'photos/1.jpg'`.

Порядок в списке `photos` = порядок появления сверху вниз:

| № | Где окажется |
|---|---|
| 1–3 | первый экран |
| 4–5 | рядом с письмом |
| 6–7 | рядом с пожеланиями |
| 8–9 | в финале |

Мемы и кадры с подписями по краям обрезать нельзя — им нужно
`fit: 'contain'`, тогда картинка показывается целиком:

```js
{ src: 'photos/mem.jpg', caption: '', tilt: 4, fit: 'contain' },
```

Подписи под снимками сейчас выключены (`caption: ''`) — впиши текст,
и под фото появится надпись от руки.

Кадры лучше квадратные — рамка кадрирует по центру. На широких экранах
поляроиды висят по углам секций, на телефоне превращаются в ленту
с горизонтальной прокруткой.

## Локальный просмотр

```bash
cd birthday
python3 -m http.server 8080
# открыть http://localhost:8080
```

## Что внутри

- первый экран: контурная типографика, имя маркером с глитчем, поляроиды;
- бегущие строки и шашечки-разделители;
- живой обратный отсчёт до 17 сентября — в сам день вместо цифр «СЕГОДНЯ»;
- письмо на тёмной карточке, пришпиленное булавками;
- пять коротких пожеланий;
- финал с подписью;
- сканлайны, зерно и падающие звёздочки поверх всего.

Уважает `prefers-reduced-motion`: при включённой настройке анимации,
глитч и звёздочки выключаются.
