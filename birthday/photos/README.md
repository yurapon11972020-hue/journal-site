# Папка для фотографий

Клади сюда снимки (`.jpg` / `.png`) и прописывай пути в `../config.js`:

```js
{ src: 'photos/1.jpg', caption: 'наш класс', tilt: -4 },
```

Пока `src: null` — на месте фото рисуется пустая поляроидная рамка.

Лучше всего смотрятся **квадратные** кадры (или близкие к квадрату) —
рамка обрезает изображение по центру.
