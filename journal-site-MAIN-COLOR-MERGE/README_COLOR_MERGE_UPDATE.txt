Обновление основной версии журнала

Что добавлено:
- Цветовое обозначение оценок в таблицах предметов и табелях.
- Цвета для 5, 4, 3, 2/1, Н, Н/У, ЭН и прочих отметок.
- Нормальное чтение объединённых ячеек Excel: если дата, месяц, тема, ФИО или заголовок находится в объединённой ячейке, сайт берёт значение из верхней левой ячейки объединения.
- Сохранены ускорения FAST-версии: кэш распарсенного журнала и фоновый прогрев.

Render:
Root Directory: journal-site-MAIN-COLOR-MERGE
Build Command: npm install --package-lock=false --registry=https://registry.npmjs.org/ --no-audit --no-fund && npm run build
Start Command: npm start
