# Подключение групп

Следуйте разделу «Запуск» в README.md. Ссылки задаются оператором на сервере. Публичные URL разрешены только для Яндекс.Диска по HTTPS; ссылки не сохраняются в аккаунтах студентов.

1. Укажите свою публичную ссылку или список в YANDEX_DISK_PUBLIC_URLS. Для явного названия используйте «Название = ссылка».
2. Для единственного журнала задайте случайный JOURNAL_ACCESS_CODE. Для нескольких групп — JOURNAL_GROUP_ACCESS_CODES с отдельным кодом на каждую группу.
3. Перезапустите сервер. Войдите с соответствующим кодом. Если файл не распознаётся, новая версия не заменит ранее проверенный кэш.
4. Проверьте название, даты, отметки и время синхронизации на известном вам примере.

Для переименования группы лучше привязывать доступ к ID. Для публичного файла ID зависит от ссылки и пути внутри папки, а не отображаемого названия. Ссылки из исходного архива не являются настройками вашей установки и удалены из шаблона.

set-yandex-env.ps1 обновляет только параметры источника/кэша и сохраняет остальные строки .env.local. Не запускайте сервер с секретами в публичном репозитории. Не передавайте коды одной группы другой.
