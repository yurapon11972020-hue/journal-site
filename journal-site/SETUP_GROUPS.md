# Несколько групп и новая ссылка на журнал

Короткая инструкция: что нажать, чтобы сайт и бот работали по новой ссылке и показывали не одну группу, а несколько.

---

## 1. Главное правило

Одна публичная ссылка на Excel-файл = одна группа на сайте.
Все ссылки перечисляются в одной переменной окружения **`YANDEX_DISK_PUBLIC_URLS`**.

Три способа записи:

| Что пишешь | Что получится |
|---|---|
| `https://disk.yandex.ru/i/ССЫЛКА` | одна группа, название = имя файла на Диске |
| `ИСиП-25/9 = https://disk.yandex.ru/i/ССЫЛКА` | одна группа с твоим названием |
| `https://disk.yandex.ru/d/ССЫЛКА` (ссылка на **папку**) | каждый Excel-файл внутри папки станет отдельной группой |

Несколько ссылок разделяются **запятой или переносом строки**:

```env
YANDEX_DISK_PUBLIC_URLS=ИСиП-25/9 = https://disk.yandex.ru/i/aaaa, ИСиП-24/9 = https://disk.yandex.ru/i/bbbb
```

## 2. Подключить ссылки на Render

1. Открой свой сервис **journal-site** на [render.com](https://dashboard.render.com).
2. Слева выбери **Environment**.
3. Нажми **Add Environment Variable** и добавь:

   | Key | Value |
   |---|---|
   | `YANDEX_DISK_PUBLIC_URLS` | `https://disk.yandex.ru/i/jr0lr00cUQp0FQ,https://disk.yandex.ru/i/QZZ5ghsJ_w7xAg,https://disk.yandex.ru/i/ezTOIqg1oAictA` |

4. **Старую переменную `YANDEX_DISK_PUBLIC_URL` (без `S` на конце) удали** — кнопка с корзиной справа от строки.
   Если её оставить, ничего не сломается: она просто игнорируется, пока задана `YANDEX_DISK_PUBLIC_URLS`. Но чтобы потом не путаться, лучше удалить.

   Список ссылок понимают **обе** переменные: если ты уже вписал несколько ссылок через запятую в старую `YANDEX_DISK_PUBLIC_URL`, сайт их прочитает и покажет все группы. Переименование нужно только для порядка.
5. Нажми **Save Changes**. Render сам пересоберёт и перезапустит сервис.
6. Дождись зелёного статуса **Live** (обычно 2–4 минуты).

Проверь, что всё поднялось:

```text
https://ТВОЙ-АДРЕС.onrender.com/api/groups
```

Ответ должен выглядеть так:

```json
{
  "count": 3,
  "groups": [
    { "groupName": "ИСиП-25-9", "url": "/group/..." },
    { "groupName": "ИСиП-24-9", "url": "/group/..." },
    { "groupName": "ИСиП-23-9", "url": "/group/..." }
  ]
}
```

В поле `configured` видно, из какой переменной сервер взял ссылки и сколько их там —
если `variable` показывает `YANDEX_DISK_PUBLIC_URL`, значит новую переменную сервер не увидел.

`count` — сколько групп увидел сайт. Сейчас в переменной три ссылки, значит должно быть `"count": 3`.
Названия групп берутся из имён файлов на Яндекс.Диске — если они выглядят не так, как хочется,
задай их сам: `ИСиП-25/9 = https://disk.yandex.ru/i/ССЫЛКА, ИСиП-24/9 = https://disk.yandex.ru/i/ССЫЛКА`.

## 3. Добавить следующие группы

Когда появится ссылка на журнал ещё одной группы:

1. Render → **Environment** → строка `YANDEX_DISK_PUBLIC_URLS` → **Edit**.
2. Допиши ссылку через запятую:

   ```env
   https://disk.yandex.ru/i/jr0lr00cUQp0FQ, https://disk.yandex.ru/i/QZZ5ghsJ_w7xAg, https://disk.yandex.ru/i/ezTOIqg1oAictA, ПКС-24/9 = https://disk.yandex.ru/i/СЛЕДУЮЩАЯ-ССЫЛКА
   ```

3. **Save Changes** → дождись **Live** → проверь `/api/groups`.

Больше ничего менять не нужно: главная страница сама покажет карточки всех групп, а бот — список групп кнопками.

### Ещё удобнее: одна ссылка на папку

Если сложить все журналы в одну папку на Яндекс.Диске и открыть публичный доступ **на папку**, то в `YANDEX_DISK_PUBLIC_URLS` достаточно одной ссылки вида `https://disk.yandex.ru/d/...`.
Тогда новая группа добавляется так: **просто положить новый Excel в папку**. Ничего на Render менять не нужно — сайт увидит файл при следующем обновлении (по умолчанию в пределах 30 минут).

Правила для такой папки:
- имя файла становится названием группы (`ИСиП-25-9.xlsx` → «ИСиП-25-9»);
- берутся файлы `.xlsx`, `.xlsm`, `.xls`, в том числе во вложенных папках (до 3 уровней);
- временные файлы Excel вида `~$файл.xlsx` пропускаются;
- максимум 60 файлов.

---

## 4. Проверка после изменений (2 минуты)

| Что открыть | Что должно быть |
|---|---|
| `/api/groups` | `count` = столько групп, сколько ссылок/файлов |
| главная страница сайта | карточки всех групп |
| страница любой группы | правильные студенты, оценки, пропуски |
| бот `/start` | если групп несколько — список групп кнопками; если одна — сразу её журнал |

## 5. Чтобы работало без перебоев

**Про ссылки на Яндекс.Диске**

- Публичный доступ у файла/папки должен быть **включён** и **не истекать по времени**.
- Не удаляй и не пересоздавай ссылку: при повторной публикации Яндекс выдаёт **новую** ссылку, и старая перестаёт работать. Если так вышло — просто впиши новую в `YANDEX_DISK_PUBLIC_URLS`.
- Файл можно спокойно **редактировать и перезаписывать** — ссылка та же, сайт подхватит изменения сам.
- Переименование файла на Диске меняет отображаемое название группы (если ты не задал его сам через `Название = ссылка`).

**Про формат Excel**

- Структура листов должна остаться такой же, как в текущем журнале: отдельный лист на предмет, лист `Табели`, номера студентов в первом столбце, ФИО во втором, строки `Средний балл` / `Уваж.` / `Неуваж.`.
- Если лист перестроить — сайт покажет ошибку разбора именно этой группы, остальные группы продолжат работать.

**Про обновление данных**

- Журнал перекачивается раз в `JOURNAL_CACHE_INTERVAL_MINUTES` минут (на Render сейчас 5) в окне с `JOURNAL_REFRESH_FROM_HOUR` до `JOURNAL_REFRESH_TO_HOUR` по местному времени (сейчас 05:00–24:00 при `JOURNAL_TIMEZONE_OFFSET_HOURS=5`).
- Каждая группа качается отдельно. Если групп станет много (больше 5–7), **увеличь интервал** до 15–30 минут, чтобы не долбить Яндекс.Диск и не тормозить бесплатный сервер.
- Если Яндекс временно недоступен, сайт продолжит показывать **последнюю скачанную копию**, а не упадёт.
- На каждую группу хранится не больше `JOURNAL_CACHE_MAX_FILES` копий (сейчас 2), старые удаляются сами.

**Про бесплатный тариф Render**

- Сервис засыпает после ~15 минут без запросов. Первый заход после сна занимает 30–60 секунд — это нормально.
- После пробуждения кэш пустой, журналы скачиваются заново.
- Память ограничена. Если групп много, не увеличивай `JOURNAL_PARSED_CACHE_SIZE` (по умолчанию 4) без необходимости.

## 6. Если что-то пошло не так

| Симптом | Причина и что делать |
|---|---|
| «Сайт запустился, но не смог прочитать группы» | Не задана `YANDEX_DISK_PUBLIC_URLS` либо в ней опечатка. Проверь строку в Render → Environment. |
| `/api/groups` возвращает `count: 0` | Ссылка ведёт на пустую папку или на файл не-Excel. Открой ссылку в браузере и проверь, что видно нужный файл. |
| Групп меньше, чем ссылок в списке | Посмотри поле `configured` в ответе `/api/groups`: там написано, из какой переменной сервер взял ссылки и сколько их. Если `linkCount` меньше числа твоих ссылок — проверь разделители: между ссылками должна быть запятая, точка с запятой или перенос строки. |
| Название группы выглядит как хвост ссылки (`jr0lr00cUQp0FQ`) | Яндекс не ответил на запрос об этом файле — так сайт показывает, какая именно ссылка не открывается. Причина будет в тексте ошибки на странице группы. |
| Ошибка `Ошибка Yandex Disk API: 404` | Публичный доступ выключен или ссылка пересоздана. В самом тексте ошибки написано, какая ссылка не открылась и из какой переменной она взята. Открой доступ заново или впиши актуальную ссылку. |
| Группа открывается, но студентов нет | Изменилась структура листов Excel. Сравни файл с журналом, который работал раньше. |
| Появились две одинаковые группы | В `YANDEX_DISK_PUBLIC_URLS` одна и та же ссылка записана дважды, либо ссылка на файл продублирована ссылкой на папку с этим же файлом. |
| Бот отвечает старыми данными | Данные обновляются по интервалу. Подожди интервал обновления или перезапусти сервис (**Manual Deploy → Restart service**). |
| Бот молчит | Проверь `TELEGRAM_BOT_TOKEN` и заново открой `/api/telegram/setup` — см. `TELEGRAM_BOT.md`. |

## 7. Локальный запуск (для проверки перед деплоем)

Создай файл `.env.local` в папке проекта (можно скопировать `.env.example`):

```env
JOURNAL_SOURCE=yandex-public-cache
YANDEX_DISK_PUBLIC_URLS=https://disk.yandex.ru/i/jr0lr00cUQp0FQ,https://disk.yandex.ru/i/QZZ5ghsJ_w7xAg,https://disk.yandex.ru/i/ezTOIqg1oAictA
JOURNAL_CACHE_INTERVAL_MINUTES=30
JOURNAL_CACHE_MAX_FILES=2
JOURNAL_CACHE_DIR=./.journal-cache
```

Запуск:

```powershell
npm install
npm run dev
```

Открой `http://localhost:3000` и `http://localhost:3000/api/groups`.

На Windows можно вместо ручного создания файла запустить помощник:

```powershell
powershell -ExecutionPolicy Bypass -File .\set-yandex-env.ps1
```

Он спросит ссылки по одной и сам соберёт `.env.local`.
