# Telegram

Бот использует тот же проверенный read-only журнал и повторяет модель доступа сайта.

- Пока коды доступа не заданы, бот отвечает всем и показывает все группы — как работал раньше.
- Как только задан хотя бы один код группы, бот требует `TELEGRAM_WEBHOOK_SECRET` и отвечает только чатам из `TELEGRAM_GROUP_ACCESS`.

Задайте TELEGRAM_BOT_TOKEN, обязательный TELEGRAM_WEBHOOK_SECRET и PUBLIC_SITE_URL. Разрешённые личные чаты задаются картой TELEGRAM_GROUP_ACCESS: {"ID_ЧАТА":"Точное название группы"}. Числовой ID должен принадлежать человеку, которому разрешён журнал. Групповые чаты и неизвестные пользователи не обслуживаются. В сообщении проверяется совпадение отправителя с владельцем личного чата.

Получать любые данные без корректного webhook secret нельзя. Для зарегистрированного чата список групп фильтруется до построения меню. Поэтому старые кнопки с индексом не переключают пользователя в другую группу. Отметки/темы/табели остаются данными внешнего источника.

Настройка webhook теперь выполняется только POST /api/telegram/setup из сессии оператора JOURNAL_ADMIN_CODE с корректным Origin. GET ничего не изменяет. Адрес назначения берётся только из PUBLIC_SITE_URL, не из x-forwarded-host. Оператор может выполнить запрос из своего same-origin HTTP-клиента с авторизованной сессией. Публичного интерфейса управления ботом нет.

Автоматические тесты подменяют отправку сообщений: реальным пользователям ничего не отправляется. При обновлении этой версии webhook/бот в реальном Telegram не настраивался.
