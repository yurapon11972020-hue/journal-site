# Телеграм-бот журнала

Бот встроен прямо в сайт. Отдельный сервер не нужен: Telegram присылает сообщения на адрес сайта (`/api/telegram`), и бот отвечает теми же данными, что показывает сайт.

## Что умеет бот

- `/start` → список групп кнопками;
- группа → сводка (студентов, средний балл, пропуски) и меню;
- 👥 **Студенты** → список с средним баллом и числом пропусков, постранично;
- студент → **табель**: каждый предмет, средний балл, Н/НУ;
- 📅 **Энки по датам** → по каждому предмету даты, когда были Н, НУ и ЭН;
- 🏆 **Рейтинг** → все студенты по среднему баллу;
- 📚 **Предметы** → преподаватель, средний по группе и рейтинг по предмету.

Навигация работает кнопками, бот редактирует одно сообщение — чат не засоряется.

## Подключение (5 минут)

### Шаг 1. Создай бота
1. Открой в Telegram бота **@BotFather**.
2. Отправь команду `/newbot`.
3. Придумай имя (например, `Журнал ИСиП`) и юзернейм (например, `isip_journal_bot`).
4. BotFather пришлёт **токен** вида `1234567890:AAAbbbCCCddd...` — скопируй его.

### Шаг 2. Добавь токен на Render
1. Открой свой сервис **journal-site** на Render.
2. Слева → **Environment**.
3. Нажми **Add Environment Variable**:
   - Key: `TELEGRAM_BOT_TOKEN`
   - Value: токен из шага 1.
4. Сохрани — Render сам перезапустит сервис. Дождись зелёного статуса **Live**.

### Шаг 3. Включи webhook (один раз)
Открой в браузере адрес (подставь свой домен Render):

```text
https://journal-site-yfev.onrender.com/api/telegram/setup
```

Должен появиться ответ `"ok": true` и фраза «Webhook установлен».

### Шаг 4. Пользуйся
Открой своего бота в Telegram и нажми **/start** (или напиши любое сообщение).

## Особенность бесплатного Render

Бесплатный сервис «засыпает» после ~15 минут без посещений. Если бот спал, **первый ответ может прийти с задержкой до минуты** — Telegram сам повторит доставку, ничего нажимать заново не нужно. Дальше отвечает быстро.

Чтобы бот не засыпал, можно бесплатно настроить «пинг» сайта раз в 10 минут через сервис вроде UptimeRobot (мониторить адрес `https://твой-домен.onrender.com/api/journal`) — либо перейти на платный тариф Render.

## Необязательная защита webhook

Можно добавить вторую переменную на Render:

- Key: `TELEGRAM_WEBHOOK_SECRET`
- Value: любая случайная строка, например `j8s3kd92mfn1`

После добавления снова открой `/api/telegram/setup` — секрет применится. Тогда посторонние запросы к webhook будут отклоняться.

## Если бот не отвечает

1. Проверь, что сервис на Render в статусе **Live**.
2. Открой `https://твой-домен.onrender.com/api/telegram/setup` ещё раз — в ответе должно быть `"ok": true`.
3. Проверь, что `TELEGRAM_BOT_TOKEN` на Render без лишних пробелов.
4. Посмотри **Logs** на Render — ошибки бота пишутся со префиксом `[telegram]`.
