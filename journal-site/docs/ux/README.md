## Как открыть прототип

Из корня приложения запустите локальный HTTP-сервер для прототипа:

~~~bash
cd docs/ux/prototype
python3 -m http.server 8000
~~~

Откройте [http://localhost:8000/](http://localhost:8000/) в браузере. В панели прототипа выберите один из четырёх экранов и ширину компьютера, планшета или телефона. Переключатель «Каркасы» показывает схемы без детального оформления. Переключатель «Режим с кодом» демонстрирует экран входа; демонстрационный код — **1234**. Учебные группы, имена и оценки в макетах вымышлены; логотип взят из действующего проекта.

Кликабельные пути прототипа просмотрены в Chromium: выбор группы и раскрытие табеля, поиск без результатов со сбросом, смена предмета, темы, мобильное меню, вход с ошибкой и успехом. На кадрах E0–E4 при 360 px проверен выход содержимого за ширину страницы; таблица E3 прокручивается внутри блока. Это проверка **прототипа**. Основной сайт и Firefox в этих материалах не отмечены проверенными.

## Основание и границы проверки

- Основания — документ КТ1 «Концепция и техническое задание проекта „Подпольный журнал“» и текст задания «Контрольная точка 2. Проектирование интерфейса и UX», предоставленные пользователем. Номера FR-01–FR-12 и NFR-01–NFR-07 из КТ1 сохранены в [актуализированном ТЗ](requirements.md).
- Сопоставление выполнено по текущему коду `app/`, `components/`, `lib/access.ts` и `middleware.ts`. Данные из Excel и конфигурация рабочего сервера не проверялись.
- Пользовательские истории в КТ1 описаны прозой, без отдельной нумерации. Предварительная структура КТ1 названа текстом; графической карты и утверждённого протокола её проверки нет. Текущая документация — **предлагаемая актуализация для КТ2**, ожидающая утверждения командой.
- Графические экраны и кликабельный прототип доступны в этом каталоге. Схемы в `wireframes.md` описывают компоновку; PNG показывают статические экспорты; HTML/CSS/JS позволяют редактировать прототип. Перед сдачей нужно разместить материалы в доступном преподавателю репозитории и проверить его права доступа.
- В КТ1 указан [адрес сайта](https://journal-site-yfev.onrender.com/). Его текущая доступность в рамках подготовки этих документов не проверялась.

## Основное проектное решение

MVP КТ1 — FR-01–FR-04: список групп, поиск студента, его карточка и оценки по предметам. Для четырёх содержательных экранов КТ2 выбраны список групп `/`, табели группы, оценки по предметам и темы занятий. Последние три уже существуют как **разные состояния интерфейса** страницы `/group/[id]`, а не как три самостоятельных URL. Условный пятый экран `/login` показывается только при включённом входе по коду. В прототипе эти состояния доступны через прямые пункты навигации; служебный параметр `?screen=…` выбирает кадр прототипа, а не новый маршрут основного сайта.

Выявленные доработки: FR-08 требует предупреждать о показе резервной копии после сбоя источника; сейчас сбой виден только в серверном журнале. NFR-07 требует безопасных текстов ошибок; сейчас пользователю или API может возвращаться сырой текст исключения. Они отмечены в ТЗ и плане команды.
