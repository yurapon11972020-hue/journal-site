# Симулятор Разработчика — исходники плейса

Мультяшный симулятор про путь от гаража до космоса. Карта, интерфейс,
монетизация и админка — всё собирается из этой папки в один файл `.rbxlx`,
который открывается в Roblox Studio.

---

## 1. Самый быстрый запуск (30 секунд)

Готовый файл уже собран и лежит в репозитории:

**`roblox-devsim/build/DevSim.rbxlx`**

1. Скачай его (в GitHub: открыть файл → кнопка **Download raw file**).
2. Двойной клик по файлу — откроется Roblox Studio.
3. Нажми **Play**. Всё.

Мир, интерфейс, зоны, стенды и лидерборды строятся сами при запуске —
руками в Studio ничего расставлять не нужно.

---

## 2. Если что-то поменял в коде

Пересобрать файл одной командой:

* **Windows:** правый клик по `roblox-devsim/build.ps1` → «Выполнить с помощью PowerShell»
* **Linux / macOS:** `./roblox-devsim/build.sh`
* **Вручную:** `python3 roblox-devsim/tools/build_place.py`

Нужен только Python 3, больше ничего.

Проверить, что нигде не сломан синтаксис Lua (по желанию):

```
npm install --no-save luaparse
node roblox-devsim/tools/check_lua.js roblox-devsim/src
```

---

## 3. Чтобы вообще ничего не собирать руками

Настрой автопубликацию: после каждого изменения GitHub сам соберёт игру
и зальёт её в твой плейс на Roblox. Три секрета, один раз, 5 минут:

→ **[docs/АВТОПУБЛИКАЦИЯ.md](docs/АВТОПУБЛИКАЦИЯ.md)**

Пока секреты не заданы, GitHub всё равно собирает игру и кладёт готовый
`.rbxlx` в артефакты вкладки **Actions** — скачивай оттуда.

---

## 4. Что где лежит

```
roblox-devsim/
├── build/DevSim.rbxlx      ← готовая игра, открывай в Studio
├── src/
│   ├── shared/
│   │   ├── Config.lua      ← ЕДИНСТВЕННЫЙ файл, который правишь руками
│   │   ├── MapKit.lua        детальки для стройки (деревья, дома, пады…)
│   │   └── MapBuilder.lua    сама карта: 5 островов, мосты, VIP-лофт
│   ├── server/MainServer.server.lua   логика, донат, награды, админка
│   └── client/ClientMain.client.lua   интерфейс, свет зон, колесо удачи
├── tools/build_place.py    сборка .rbxlx без Studio и Rojo
├── tools/check_lua.js      проверка синтаксиса
├── default.project.json    для тех, кто пользуется Rojo
└── docs/                   инструкции
```

Если пользуешься **Rojo** — просто `rojo serve` из папки `roblox-devsim`.

---

## 5. Что нужно сделать на сайте Roblox

Игра работает и без этого, но Robux без этого не будет:

1. Создай геймпассы и Developer Products (Creator Hub → твоя игра →
   Monetization).
2. Вставь их ID в `src/shared/Config.lua` (блок 2, самый верх файла).
3. Пересобери / дождись автопубликации.

Подробно, с ценами и порядком — **[docs/МОНЕТИЗАЦИЯ.md](docs/МОНЕТИЗАЦИЯ.md)**.

Товары с ID = 0 не ломают игру: кнопка просто покажет «СКОРО».

---

## 6. Админка

* Ctrl + K — открыть панель (или написать в чат `devpanel`).
* RightShift — спрятать/показать.
* Работает у владельца игры, в Studio и у тех, чей UserId вписан
  в `Config.ADMINS`.

---

## 7. Карта и сюжет

Пять островов в небе, соединённых мостами. Каждый — своя эпоха карьеры,
со своим светом, палитрой и декором:

| # | Остров | Эпоха | Что там |
|---|--------|-------|---------|
| 1 | Гараж | утро, 2009 | дом с гаражом, велик, кольцо, стопка коробок пиццы |
| 2 | Стартап-офис | день | стекло, неоновая вывеска, кофемашина, доска со стикерами, пинг-понг |
| 3 | IT-кампус | полдень | три корпуса, стеклянный купол, фонтан, серверные стойки, дроны |
| 4 | Кремниевая долина | закат | золотые башни, бассейн, вертолёт, спорткар, фонтан из денег |
| 5 | Космо-штаб | ночь | станция, ракета на старте, планета, спутники, ИИ-ядро |

Плюс **VIP-лофт** — отдельный золотой остров в небе для владельцев
геймпасса VIP.

Как всё это менять — **[docs/КАРТА.md](docs/КАРТА.md)**.
