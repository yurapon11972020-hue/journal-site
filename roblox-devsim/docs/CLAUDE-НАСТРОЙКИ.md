# Что включить в Claude (Customize), чтобы работать над плейсом

Честно и по делу: **отдельного плагина или коннектора для Roblox
в каталоге нет** — я проверил. Roblox не даёт публичного API, к которому
Claude мог бы подключиться напрямую (кроме Open Cloud для публикации,
а он уже настроен через GitHub Actions).

Поэтому список ниже — то, что реально помогает, а не «для галочки».

---

## 1. Уже настроено в этом репозитории

### Скилл проекта `roblox-devsim` ✅ создан

Лежит в `.claude/skills/roblox-devsim/SKILL.md`. Любая новая сессия
Claude в этом репозитории сразу знает: где что лежит, каким синтаксисом
писать, как пересобрать плейс и чего не ломать.

Без него каждый раз пришлось бы объяснять заново. Ничего включать не
надо — работает само.

### GitHub-коннектор ✅ уже подключён

Именно он даёт автосборку и автопубликацию.

---

## 2. Что стоит включить в Customize

### Плагин **Design** — рекомендую

`Customize → Plugins → Design`

Зачем именно тебе: у тебя есть файл с промтами для иконок и обложки.
Плагин добавляет разбор макетов, работу с дизайн-системой и подключение
к Figma. Полезен для:

* обложки игры и иконки (то, от чего реально зависят клики);
* единого стиля интерфейса (цвета, отступы, шрифты);
* критики готовой картинки — «почему эта обложка не кликается».

### Встроенные скиллы (включать ничего не нужно, просто зови командой)

| Команда | Когда пригодится |
|---|---|
| `/design` | сделать макет интерфейса или обложки — редактируется мышкой прямо в браузере |
| `/code-review` | проверить Lua на баги перед публикацией |
| `/security-review` | поискать дыры, через которые читеры накрутят деньги |
| `/session-start-hook` | чтобы в веб-сессии сразу подтягивались зависимости и проверки |
| `/loop` | повторяющиеся задачи (например, раз в день проверять сборку) |
| `/skill-creator` | сделать ещё скиллов под свои задачи |

### Чего НЕ надо включать

* **Unity** — плагин про игры, но это движок Unity, а не Roblox. Для
  твоего проекта бесполезен, только займёт место в контексте.
* Всё остальное в каталоге (Carta, Lusha, Box, Dropbox, Bigdata) —
  бизнес-инструменты, к Roblox отношения не имеют.

## 3. Как этим пользоваться дальше

Просто пиши задачу словами, скилл проекта подхватится сам:

* «добавь на кампус скейт-парк»
* «сделай зону 6 — метавселенная»
* «подними цены на бусты и добавь товар за 999 R$»
* «проверь код на читы» → я позову `/security-review`
* «пересобери и опубликуй» → сборка + автопубликация

Отдельно генерировать картинки я не умею — для иконок и обложки
пользуйся промтами из своего файла и любой нейросетью для изображений,
а готовые PNG заливай в Creator Hub → Images. Пришлёшь мне assetId —
вставлю их в интерфейс вместо эмодзи (в `Config.lua` для этого уже есть
место).
