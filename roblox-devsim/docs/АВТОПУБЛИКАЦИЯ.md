# Автопубликация: чтобы ничего не заливать руками

Настраивается один раз. После этого любое изменение кода само уезжает
в твою игру на Roblox: GitHub собирает `.rbxlx` и публикует его через
официальный Open Cloud API.

---

## Шаг 1. Узнать два ID

Открой свою игру на **create.roblox.com**.

* **Universe ID** (он же Experience ID) — в адресной строке:
  `create.roblox.com/dashboard/creations/experiences/`**`1234567890`**`/overview`
* **Place ID** — открой внутри игры нужное место, в адресе будет
  `.../places/`**`9876543210`**`/...`
  (Place ID видно и в обычной ссылке на игру: `roblox.com/games/`**`9876543210`**`/...`)

Запиши оба числа.

---

## Шаг 2. Сделать ключ Open Cloud

1. **create.roblox.com** → аватарка справа сверху → **Credentials**
   (или сразу `create.roblox.com/credentials`).
2. **Create API Key**.
3. Заполни:
   * **Name:** `github-publish` (любое)
   * **Access Permissions:** добавь **Place Management** → выбери свою
     игру → права **Write**
   * **Security → Accepted IP Addresses:** впиши `0.0.0.0/0`
     (GitHub каждый раз запускается с нового адреса)
   * **Expiration:** максимальный срок
4. **Save & Generate Key** → скопируй ключ.
   Он показывается **один раз** — не закроешь страницу, пока не вставишь.

---

## Шаг 3. Положить всё в секреты GitHub

Репозиторий → **Settings** → **Secrets and variables** → **Actions** →
**New repository secret**. Создай три штуки:

| Имя секрета | Что вставить |
|---|---|
| `ROBLOX_API_KEY` | ключ из шага 2 |
| `ROBLOX_UNIVERSE_ID` | первое число из шага 1 |
| `ROBLOX_PLACE_ID` | второе число из шага 1 |

Имена — ровно такие, буква в букву.

---

## Шаг 4. Проверить

Вкладка **Actions** → слева workflow **«Roblox — сборка и публикация
места»** → **Run workflow**.

Через минуту в логе появится `HTTP 200` и «Игра опубликована».
Заходи в игру — она уже новая.

---

## Что происходит дальше

Каждый раз, когда меняется что-то в папке `roblox-devsim/`:

1. проверяется синтаксис всех Lua-файлов;
2. собирается `DevSim.rbxlx`;
3. файл кладётся в артефакты (вкладка Actions — можно скачать);
4. игра публикуется в Roblox.

---

## Если что-то пошло не так

| Ошибка в логе | Причина | Что делать |
|---|---|---|
| `HTTP 401` | ключ неверный или истёк | сделать новый ключ |
| `HTTP 403` | у ключа нет прав на это место, или не разрешён IP | добавить Place Management → Write на нужную игру, вписать `0.0.0.0/0` |
| `HTTP 404` | перепутаны Universe ID и Place ID | проверить шаг 1 |
| «Секреты Roblox не заданы» | секретов нет | шаг 3 |

**Важно:** ключ Open Cloud — это пароль от твоей игры. Он живёт только
в секретах GitHub; в коде его нет и быть не должно. Если случайно
засветил — удали ключ на create.roblox.com и сделай новый.
