# Карта: как устроена и как её менять

Карта не лежит в файле места — она **строится кодом при запуске**.
Поэтому её легко править: поменял число в конфиге → перезапустил.

```
Гараж ──мост── Стартап ──мост── Кампус ──мост── Долина ──мост── Космос
  ▲                                    ☁ VIP-лофт (отдельный остров в небе)
спавн, доски лидеров,
колесо, сундук, коды, донат
```

---

## Из чего состоит

| Файл | За что отвечает |
|---|---|
| `src/shared/Config.lua` | зоны: названия, множители, требования, палитра, свет |
| `src/shared/MapKit.lua` | детальки: дома, деревья, фонари, мосты, ворота, пады, стенды |
| `src/shared/MapBuilder.lua` | сама сборка: что и где стоит на каждом острове |

## Быстрые правки

**Поменять цвет зоны** — `Config.ZONES[i].palette`:

```lua
palette = {
    ground  = Color3.fromRGB(126, 205, 96),  -- трава
    ground2 = ...,                            -- кант травы
    rock    = ...,                            -- скала под островом
    accent  = ...,                            -- неон, вывески, кант
    wall    = ..., roof = ..., trim = ...,    -- постройки
}
```

**Поменять настроение (время суток)** — `Config.ZONES[i].sky`:

```lua
sky = {
    clock = 17.4,      -- время суток: 7 = утро, 12 = день, 17.5 = закат, 0 = ночь
    brightness = 2.4,
    fog = Color3...,   -- цвет дымки
    density = 0.32,    -- насколько плотная дымка
    saturation = 0.2,  -- насыщенность картинки
    stars = 0,         -- сколько звёзд (для космоса — 4000)
}
```

Свет переключается **на клиенте**, когда игрок заходит в зону, и плавно
перетекает за 1.6 секунды. У каждого игрока свой — сервер не нагружается.

**Размеры мира** — `Config.ISLAND` (размер острова) и `Config.ZONE_GAP`
(расстояние между центрами островов; длина моста = разница между ними).

**Требования к зоне** — `needRebirth` и `needMoney`. Ворота на мосту
сами покажут актуальный текст.

## Добавить свой предмет на карту

Открой `MapBuilder.lua`, найди функцию своей зоны (`decorGarage`,
`decorStartup`, `decorCampus`, `decorValley`, `decorSpace`) и добавь
строчку. Всё, что есть в наборе:

```lua
Kit.part({Size = Vector3.new(4,4,4), Position = c + Vector3.new(10,5,0), Color = ...}, folder)
Kit.tree(c + Vector3.new(40, 3, 20), folder, "oak")     -- "oak" / "pine" / "palm"
Kit.bush(pos, color, folder)      Kit.flowers(pos, color, folder)
Kit.rock(pos, folder)             Kit.cloud(pos, folder)
Kit.lamp(pos, color, folder)      Kit.fence(center, half, color, folder)
Kit.bench(pos, folder)            Kit.crate(pos, folder)
Kit.coin(pos, folder)             Kit.serverRack(pos, accent, folder)
Kit.building({pos = ..., width = 40, height = 26, depth = 26, title = "ОФИС"}, folder)
Kit.tower(pos, floors, wall, accent, folder, "IPO")
Kit.pad(pos, size, color, "ПОДПИСЬ", folder)
Kit.stand(pos, {icon = "🛒", title = "МАГАЗИН"}, folder)
Kit.arch(pos, width, height, "ТЕКСТ", color, folder, rotY)
Kit.holoRing(pos, diameter, color, folder)
```

`c` — центр острова, `folder` — куда класть. Координаты локальные:
`c + Vector3.new(x, y, z)`.

## Оживить деталь

Анимация помечается тегом и проигрывается **у каждого игрока локально**,
поэтому её можно вешать хоть на сотню объектов — сеть не нагрузится:

```lua
Kit.markSpin(part, 2, "Y")                       -- крутится
Kit.markBob(part, 1.5, 1.2)                      -- качается вверх-вниз
Kit.markPulse(part, 1.2)                         -- пульсирует светом
Kit.markOrbit(part, center, radius, speed, bob)  -- летает по кругу
```

---

## Сколько это тянет

Вся карта — порядка тысячи деталей, все `Anchored`, декор без
коллизий. Спокойно работает на телефоне. Если добавляешь много своего —
ставь `CanCollide = false` (или используй `Kit.deco` вместо `Kit.part`).
