# Монетизация: что создать на сайте и зачем

В игре уже готова вся механика — не хватает только ID товаров.
Создаёшь товар на сайте → копируешь ID → вставляешь в
`src/shared/Config.lua`. Товар с ID = 0 просто показывает «СКОРО»
и ничего не ломает.

---

**Почему именно эти.** В симуляторах основные деньги приносят не
разовые геймпассы, а то, что покупают снова и снова:

* **Стартовый набор** — самая покупаемая позиция в жанре: дёшево,
  выгодно, видно сразу на входе.
* **Буст всему серверу** — покупает один, радуется весь сервер, имя
  героя висит в баннере. Дальше срабатывает социальное давление —
  берут ещё.
* **Временные бусты и прокруты колеса** — маленький чек, но постоянный.

## Часть 3. Куда вставлять ID

Открой `src/shared/Config.lua`, блок 2 (в самом верху). Там два списка:

```lua
Config.GAMEPASSES = {
    AutoClick   = 1879846483,
    ...
    LuckyPass   = 0,   -- <- сюда ID нового пасса
    Turbo       = 0,   -- <- и сюда
}

Config.PRODUCTS = {
    ...
    StarterPack  = 0,  -- <- сюда ID нового товара
    ServerBoost  = 0,
}
```

Цены в `Config.PRICES` — только для подписей в меню и для лидерборда
донатеров. Настоящая цена ставится на сайте Roblox.

После правки — пересобрать (`build.ps1`) или просто запушить, если
включена автопубликация.

## Часть 4. Что уже работает и приносит без всяких настроек

* **Ежедневный сундук** — 7 дней подряд, награда растёт, на 7-й день
  ребёрт. Возвращает игроков.
* **Сундук за время в игре** — каждые 8 минут, сумма растёт. Держит
  в игре.
* **Колесо удачи** — бесплатный прокрут раз в 15 минут (и платный
  за Robux). Джекпот выкрикивается на весь сервер.
* **Коды** — `Config.CODES`. Раздавай в описании игры, в группе,
  в TikTok — это бесплатный трафик.
* **Два лидерборда** в хабе: топ по деньгам и **топ донатеров**.
  Второй — прямой мотиватор: люди донатят, чтобы попасть в список.

## Часть 5. Что сделать вне кода (без этого игру не найдут)

1. **Иконка и обложка.** Промты для нейросети уже есть в твоём файле
   с промтами — сделай картинки и загрузи в Creator Hub → Images.
2. **Название и описание.** В описании: что за игра, список кодов,
   ссылка на группу.
3. **Группа Roblox.** Впиши её ID в `Config.GROUP_ID` — потом можно
   выдавать награду за вступление.
4. **Первые игроки.** Друзья, TikTok/Shorts с моментом «выбил ребёрт
   на колесе», Roblox-паблики.

Одна честная мысль: сама по себе игра не станет популярной от кода.
Механика тут уже на уровне жанра — дальше решают обложка, название
и трафик. Код к этому готов: он выдерживает наплыв игроков, сохраняет
прогресс и не даёт себя ломать эксплойтами.
